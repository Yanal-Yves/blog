# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A French-language technical documentation site ("Notes Techniques") built with **Hugo** using the **hugo-book** theme. Statically generated, deployed to GitHub Pages at https://yanal.fargialla.com. All content is written in French.

## Commands

```bash
# First clone only — the theme is a git submodule and themes/ is empty without this
git submodule update --init --recursive

hugo server          # local dev server at http://localhost:1313/
hugo --minify        # production build into public/ (what CI runs)
```

There are no tests or linters. Deployment is automatic: pushing to `main` triggers `.github/workflows/` which builds with Hugo extended and publishes `public/` to GitHub Pages with the `yanal.fargialla.com` CNAME. `public/` is committed but regenerated by CI — do not hand-edit it.

## Content structure

Articles live in `content/<section>/`. Each section has an `_index.md` (with `bookCollapseSection: true` for collapsible nav) and ordered article files. Page ordering everywhere is controlled by the `weight` front matter field, not filename.

Front matter conventions used across the site:
- `title` — for numbered series, follows the `"SPF (Sender Policy Framework) - 4/9"` pattern
- `description` — set on every page; used for SEO meta tags
- `weight` — controls ordering in nav and article lists
- `enableGitInfo = true` in `hugo.toml` means the "last updated" date comes from git history automatically — do not add a `lastmod`/`date` field for that purpose

## Writing conventions

- **Never put a link inside bold text** (no `**[label](url)**`). The rendering is poor. Use a plain link `[label](url)`, or bold a separate word — but never both on the same text.

## Theme customizations (the non-obvious parts)

The global table of contents is **disabled** (`BookToC = false`). Custom pieces compensate:

- `layouts/shortcodes/toc.html` — a per-page inline ToC. Articles that want a ToC must explicitly include `{{< toc >}}` at the top. Styled by `.book-toc-inline` in `assets/_custom.scss`.
- `layouts/shortcodes/list-articles.html` — `{{< list-articles >}}` renders child pages ordered by weight; used in section `_index.md` files to build the article index.
- `layouts/partials/docs/inject/content-after.html` — injected at the bottom of **every** page: author byline, git-derived update date, the "AI-assisted, author-reviewed" notice, and the CC BY-SA 4.0 license.
- `layouts/partials/docs/inject/content-before.html` — renders the H1 page title.
- `layouts/partials/docs/inject/head.html` — Mermaid diagram styling (forces white background).
- `layouts/robots.txt` — custom robots.txt with sitemap directive (`enableRobotsTXT = true`).

`disableKinds = ["taxonomy", "term"]` — tags/categories pages are intentionally not generated.
